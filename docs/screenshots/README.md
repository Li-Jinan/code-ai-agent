- `login-email.png`：邮箱验证码登录 / 注册
- `app-generating.png`：创建应用与 AI 生成过程
- `generated-preview.png`：生成结果预览
- `generated-edit-mode.png`：可视化编辑模式

根目录 `README.md` 使用相对路径引用这些图片。
